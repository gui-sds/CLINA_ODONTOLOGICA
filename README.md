# Clínica odontológica GS RISE

Site em HTML, CSS e JavaScript puros, inspirado no portfólio GS RISE.

Execute `npm start` nesta pasta e acesse **http://localhost:3000**.

Os arquivos editáveis estão em `gs-rise-odontologia/`. Veja as instruções de personalização no README dessa pasta.

## Publicar na Vercel

Use a raiz do repositório como **Root Directory** (deixe o campo vazio ou use `.`).
O arquivo `vercel.json` configura o preset **Other**, executa `npm run build` e
publica a pasta `gs-rise-odontologia/dist`.

Depois de enviar as alterações ao GitHub, faça um novo deploy da versão atualizada.
O comando `npm start` serve apenas para desenvolvimento local; a Vercel publica os
arquivos estáticos gerados pelo build.
